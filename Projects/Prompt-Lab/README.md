# Prompt Lab

An interactive prompt engineering learning lab built through iterative AI-assisted development.

Prompt Lab teaches prompt engineering through hands-on practice. Users write prompts, receive a structured score out of 100, get feedback, compare prompt quality, and explore simulated AI responses.

### Key Features

- 10 interactive prompt-engineering lessons
- 0–100 heuristic prompt scoring
- Evaluation across role, context, format, specificity, and clarity
- Prompt improvement feedback
- Before-and-after prompt comparison
- Simulated AI responses
- Practice history and progress tracking
- Browser-based local progress persistence

### Why It Matters to My AI Security Journey

This project helped me develop a practical understanding of prompt structure, specificity, context, iterative refinement, and AI-assisted development.

These concepts provide useful foundational knowledge for further work in areas such as prompt injection, AI red teaming, and AI application security.
