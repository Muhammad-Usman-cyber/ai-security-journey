# Prompt Injection Defense Lab

An interactive AI security lab built through iterative AI-assisted development.

Prompt Injection Defense Lab teaches prompt injection attacks and defenses through hands-on practice. Users study simulated attack scenarios, write defensive system prompts, receive a structured score out of 100, get feedback, and compare weaker vs. stronger defensive approaches.

## Key Features

- 10 interactive prompt injection lessons
- 0–100 heuristic security scoring
- Evaluation across instruction hierarchy, scope limitation, data protection, and defense-in-depth
- Security feedback highlighting policy weaknesses
- Before-and-after defense comparison
- Simulated attack scenarios and AI responses
- Practice history and progress tracking
- Browser-based local progress persistence

## Why It Matters to My AI Security Journey

This project helped me develop a practical understanding of prompt injection, instruction hierarchy, instruction/data separation, and defense-in-depth. It builds directly on Prompt Lab's foundation in prompt structure and connects traditional cybersecurity concepts — trust boundaries, least privilege, input validation — to securing AI-powered applications.
